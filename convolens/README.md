# ConvoLens — AI-Powered Behavioral Conversation Analyzer

> This system analyzes behavioral and emotional patterns in text conversations using NLP.
> It does NOT scientifically determine truthfulness, intent, or relationship quality.

## Quick Start

```bash
# 1. Create virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Mac/Linux

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the app
streamlit run app.py
```

App opens at http://localhost:8501

## Tech Stack
Python | Streamlit | NLTK | VADER | scikit-learn | Pandas | Plotly
